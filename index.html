FAQ

Is this program for beginners?

This program is best for women who already have some weightlifting experience. But I personally help you start where you are. You don't need to be "ready." You just need to start.

How many workouts are there per week?

The program includes 3 structured workouts per week with an optional 4th to accelerate progress.

Do I need a gym?

Nope! There are both gym and dumbbell-only workouts included. You'll need at least one lighter and one heavier set of dumbbells.

Can I pay monthly?

We ask for a 3-month minimum commitment so you see results. One month isn't enough.

How long until I see results?

You'll feel stronger within 2-3 weeks. Visible changes typically appear around week 8-12.

What if I have restrictions?

If you have injuries or limitations, email us at info@christenstrags.com and we'll adapt movements for you.
